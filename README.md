## Description

* This repository contains the MATLAB code for numerical experiments presented in the paper "*Generalized low-tubal-rank tensor approximation under the M-product*".
* This scientific paper is under review.
* In this paper, we study the generalized low-tubal-rank tensor approximation (GLTRTA) problem under the M-product framework. We derive a closed-form characterization of the optimal solution together with a formula for the minimum approximation error. These results extend the classical matrix approximation theory to the tensor setting under the M-product framework and avoid the use of iterative schemes previously proposed for solving the GLTRTA problem. In addition, the proposed framework is applied to a data-driven image reconstruction problem. Numerical experiments demonstrate that the proposed method effectively reduces noise and avoids iterative optimization methods.
